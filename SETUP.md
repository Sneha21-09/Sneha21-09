## Upload steps

1. Open `https://github.com/Sneha21-09/Sneha21-09`.
2. Extract this ZIP on your computer.
3. Upload the **contents** of the extracted `Sneha21-09-main` folder into the repository root. Keep the GIFs, SVGs, README and `profile-3d-contrib` folder at the same relative paths shown in the ZIP. Do not move the GIFs into an `assets` folder.
4. Make sure `.github/workflows/profile-3d.yml` is also uploaded at that exact path. On Windows, `.github` may be hidden; enable **View → Show → Hidden items** in File Explorer if needed.
5. Commit the changes to the `main` branch.
6. Open the repository's **Actions** tab, select **Anya's 3D Contribution Skyline**, and choose **Run workflow**. Wait for the run to finish successfully.
7. Open `https://github.com/Sneha21-09` and refresh. GitHub may take a short time to refresh the profile README.
